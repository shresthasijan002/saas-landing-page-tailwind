# Saas-yy — Modern SaaS Landing Page (HTML & Tailwind CSS)

A complete, dark-themed SaaS landing page built using **HTML5** and **Tailwind CSS**. This project brings together reusable UI components—including a responsive navigation bar, split hero section, feature cards, 3-tier pricing plans, a contact form, and a multi-column footer—into a cohesive single-page layout.

## Features
- **Navigation Bar:** Clean header with brand logo and navigation links (`Home`, `Contact`, `Services`).
- **Split Hero Section:** Bold headline, value proposition copy, primary CTA button, and product showcase visual.
- **Core Features Grid:** Three-column card layout highlighting key product benefits (*Fast Performance*, *Responsive Design*, *Easy Customization*).
- **3-Tier Pricing Plans:** Side-by-side comparison cards for **Basic** (`$19/month`), **Pro** (`$49/month`), and **Enterprise** (`$99/month`) plans.
- **Contact Us Section:** Styled dark-mode contact form with first/last name inputs, email field, feedback textarea, terms checkbox, and submit CTA.
- **Multi-Column Footer:** Brand copyright, quick navigation links, and social media icons.

## Tech Stack
- **HTML5**
- **Tailwind CSS**
